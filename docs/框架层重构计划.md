## 二、性能设计原则（本项目的加分项）

天坦是 Java + 大量对象分配。我们要在每个关键路径上超越它：

| 维度 | 天坦做法 | 本项目做法 |
|---|---|---|
| 事件队列 | `ArrayDeque` 每轮 new 节点 | **环形缓冲**，预分配数组，零 GC |
| 事件对象 | `AccessibilityEvent.obtain()` 拷贝 | 同（必须拷贝，但回收路径明确） |
| 字符串拼接 | `SpannableStringBuilder` 每次 new | **StringBuilder 复用 + 早退** |
| 节点排序 | 每次遍历重新 `sortedWith` | **按节点缓存排序结果**（同父节点复用） |
| 可聚焦判定 | 每次递归重算 | **按节点+代数缓存**，窗口变化才失效 |
| 锁竞争 | 大范围 synchronized | **分段锁 + 无锁读**，无障碍线程只写 |
| TTS 实例 | 服务启动即建 2 个 | **B 通道懒创建**（多数用户不触发） |
| 焦点记录 | 单条（够用） | 单条 + **轻量环形历史**（供诊断） |

## 五、关键决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| TTS 实例管理 | `TtsManager` 删除，统一走 `SpeechEngine` | 避免两套 TTS 逻辑 |
| 导航粒度 | 先保留旧 4 粒度 | 26 种导航属功能层，本轮不换 |
| 节点回收 | **不调用 recycle** | 天坦 `x0()` 是空实现，主动禁用 |
| 防环集合 | identity 语义 | 与天坦 `o0.w` 等价（见笔记 02） |
| 事件队列满 | 丢最旧 | 新事件时效性更强 |
| 音频焦点 | 双通道都空闲才释放 | 天坦行为 |
