## 给用户的验证清单（按风险排序，一次装机验完）

### 必须验（坏了等于功能不存在）

**① 粒度导航**（#1 + #9，两者要一起验）
- 切到「按字」导航 → 按下一个字 → **应只念一个字**，不是整段
- 切到「按字词」→ 应只念一个词
- 这是 P0-2 + BUG-1 的联合验收；BUG-1 若没修，会念整段

**② 跨窗口导航**（#2）
- 打开一个弹窗 → 按「窗口导航」→ 应能走进去
- 再按 → 应能走出来

**③ 输入法上屏**（#6）
- 调出输入法 → 双击候选词 → **应能上屏**
- 注意：当前**没有 AIDL 入口**，只能验「降级的节点点击路径」
  是否生效；官方 `commitText` 路径需要自家输入法配合才能验

### 应该验（坏了影响体验）

**④ 滚动定位**（#4）
- 长列表里切到「跳到顶部」→ 按导航 → 应直接到顶
- 「跳到底部」用 `Integer.MAX_VALUE` 让容器 clamp，**不同 App 行为可能不同**

**⑤ 网页元素导航**（#5）
- 浏览器里切到「链接」→ 导航 → 应能按 HTML 语义跳
- 切到「链接」时，语音应念「**网页链接**」而不是「链接」

**⑥ 窗口几何分类**（#7）
- 遍历应用内容时，**不应**滑到状态栏的时间/电量上
- 这条依赖几何容差（5px），HyperOS 的实际尺寸可能不同于我假设的

### 顺带验（低风险）

**⑦ 垂直遍历**（#3）
**⑧ 进度播报**（#8）— 调音量时听是否念「百分之XX」
