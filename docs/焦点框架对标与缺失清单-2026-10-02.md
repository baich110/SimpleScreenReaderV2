## 零、一句话结论

**我们的焦点系统只做了「遍历层」，缺了「窗口层」和「恢复层」。**

天坦和 TalkBack 的焦点系统都是三层结构：

```
┌─────────────────────────────────────────────────────────┐
│ ① 遍历层 —— 在无障碍树里走                              │
│    天坦：C1423r.v()/y()   TalkBack：OrderedTraversal     │
│    我们：TatansTraversal  ✅ 已对齐                      │
├─────────────────────────────────────────────────────────┤
│ ② 窗口层 —— 在多个窗口之间走                            │
│    天坦：M6/h.java:1095-1150                            │
│    TalkBack：searchTargetInNextOrPreviousWindow         │
│    我们：❌ 完全没有                                     │
├─────────────────────────────────────────────────────────┤
│ ③ 恢复层 —— 焦点丢了把它找回来                          │
│    天坦：retryAutoScroll / handleViewAutoScrolled /      │
│          onAutoScrollFailed / ScreenStateChange          │
│    我们：⚠️ 简化版（无 boundsChanged / 无失败回调）      │
└─────────────────────────────────────────────────────────┘
```

**这直接解释了真机反馈的「焦点会丢失、找不到焦点」——**
**一旦焦点离开当前窗口（弹窗 / 输入法 / 悬浮窗 / 分屏），或者滚动后原节点被回收，我们没有任何机制把它找回来。**

## 二、P0-1：跨窗口导航 —— 完全没有

### 现象

- 弹出对话框（新窗口）时，滑动浏览**走不出当前窗口**，焦点卡死
- 输入法弹起后，无法从输入框导航到输入法候选词
- 悬浮窗 / 分屏 / 画中画 —— 全部无法导航
- **用户反馈的「焦点丢失、找不到焦点」大概率就是这里**

 *   无障碍树是「多窗口」结构：应用窗口、输入法窗口、系统窗口、
 *   悬浮窗、分屏窗口。只在一个窗口内遍历，遇到弹窗/输入法就卡死。

 *   ② 用过滤器筛（4 种：可聚焦 / 常规 / 非当前 / 非活动）
 *   ③ 按方向取前一个/后一个（带环绕），从新窗口 root 找第一个焦点

object WindowTraversal {

    /** 窗口类型常量（对齐 AccessibilityWindowInfo） */
    const val TYPE_APPLICATION = 1
    const val TYPE_INPUT_METHOD = 2
    const val TYPE_SYSTEM = 3
    const val TYPE_ACCESSIBILITY_OVERLAY = 4

            type != TYPE_SYSTEM) {

        WindowFilter { w -> w != null && !w.isActive }

    /**
     * 跨窗口找下一个焦点 —— 1:1 抄天坦 M6/h.java:1095-1150
     *
     * @param service 无障碍服务
     * @param forward true = 前向，false = 后向
     * @param filter 窗口过滤器（默认 FOCUSABLE）
     * @return 新窗口里的第一个可聚焦节点；null = 没有可用窗口
     */
    fun navigateToNextWindow(
        service: android.accessibilityservice.AccessibilityService,
        forward: Boolean,
        filter: WindowFilter = FOCUSABLE
    ): AccessibilityNodeInfo? {
        // ① 拿当前窗口 ID
        val currentId = currentWindowId(service)

        // ② 拿全部窗口
        val all = try {
            service.windows
        } catch (e: Throwable) {
            ReaderLog.w("WindowTraversal", "getWindows 失败: ${e.message}")
            return null
        }
        if (all.isNullOrEmpty()) return null

        // ③ 用过滤器筛
        val list = ArrayList<AccessibilityWindowInfo>(all.size)
        for (w in all) {
            if (filter.accept(w)) list.add(w)
        }
        if (list.isEmpty()) return null

        // ④ 只有一个且就是当前 → 不跨
        if (list.size == 1 && list[0].id == currentId) return null

        // ⑤ 找当前窗口下标
        var idx = 0
        for (i in list.indices) {
            if (list[i].id == currentId) break
            idx++
        }

        // ⑥ 按方向取下一个（带环绕）
        var next = if (forward) idx + 1 else idx - 1
        if (forward && next >= list.size) {
            next = 0
        } else if (!forward && next < 0) {
            next = list.size - 1
        }

        // ⑦ 从新窗口 root 找第一个焦点
        val newRoot = list[next].root ?: return null
        return FocusSearch.findFirstFocus(
            TraversalStrategyFactory.create(newRoot),
            newRoot,
            if (forward) TraversalDirection.FORWARD else TraversalDirection.BACKWARD
        )

    ): Int {
        return try {
            service.windows?.firstOrNull { it.isActive }?.id ?: -1
        } catch (e: Throwable) {
            -1
        }
    }

    /** 子树里有没有可聚焦节点 —— 对应天坦 AbstractC3693m.P(root, filter) */
    private fun hasFocusableInSubtree(root: AccessibilityNodeInfo): Boolean {
        return try {

            val count = root.childCount
            for (i in 0 until count) {
                val child = root.getChild(i) ?: continue
                if (hasFocusableInSubtree(child)) return true
            }
            false
        } catch (e: Throwable) {
            false
        }
    }

    /** 全部窗口（诊断） */

        return try {
            service.windows?.joinToString(" | ") { w ->

        } catch (e: Throwable) {

        }

### 我们缺的（对比 `AutoScrollManager.kt`）

| 天坦 | 我们 | 影响 |
|---|---|---|
| `MAX_MULTIPLE_AUTO_SCROLL_ATTEMPT = 100` | `MAX_RETRY = 40` | 重试次数少 60% |
| `AutoScrollInfo`（6 字段） | `ScrollTask`（4 字段） | 缺 `isSingleColumList` / `boundsBeforeScroll` |
| `boundsChanged` 判定 | ❌ 无 | **无法判断滚动是否真的生效** |
| `onAutoScrollFailed()` 回调 | ❌ 无 | **滚动失败后无兜底** |
| `assumeScrollSuccess()` | ❌ 无 | 某些场景误判失败 |
| `targetType` 决定 action 码（6/8/10） | 只用 `applyFocus` | 聚焦动作粒度不够 |

### 现状（`SpatialTraversal.kt`）

### TalkBack 原版（`DirectionalTraversalStrategy.java:343-427`）

```java
private boolean isBetterCandidate(int direction, Rect source, Rect rect1, Rect rect2) {
    // ① 候选资格判定（比我们的 isToDirectionOf 严格得多）
    if (!isCandidate(source, rect1, direction)) return false;

    // ② rect2 不是候选 → rect1 胜
    if (!isCandidate(source, rect2, direction)) return true;

    // ③ ★ 缺：beam 判定
    if (beamBeats(direction, source, rect1, rect2)) return true;

    // ④ ★ 缺：反向 beam 判定
    if (beamBeats(direction, source, rect2, rect1)) return false;

    // ⑤ ★ 缺：加权距离（13 倍主轴权重）
    return getWeightedDistanceFor(
            majorAxisDistance(direction, source, rect1),
            minorAxisDistance(direction, source, rect1))
        < getWeightedDistanceFor(
            majorAxisDistance(direction, source, rect2),
            minorAxisDistance(direction, source, rect2));
}

// ===== isCandidate（比 isToDirectionOf 严格）=====
private boolean isCandidate(Rect srcRect, Rect destRect, int direction) {
    switch (direction) {
        case SEARCH_FOCUS_LEFT:
            return (srcRect.right > destRect.right || srcRect.left >= destRect.right)
                    && srcRect.left > destRect.left;
        case SEARCH_FOCUS_RIGHT:
            return (srcRect.left < destRect.left || srcRect.right <= destRect.left)
                    && srcRect.right < destRect.right;
        case SEARCH_FOCUS_UP:
            return (srcRect.bottom > destRect.bottom || srcRect.top >= destRect.bottom)
                    && srcRect.top > destRect.top;
        case SEARCH_FOCUS_DOWN:
            return (srcRect.top < destRect.top || srcRect.bottom <= destRect.top)
                    && srcRect.bottom < destRect.bottom;
    }
    throw new IllegalArgumentException("direction must be a SearchDirection");
}

// ===== beamBeats =====
private boolean beamBeats(int direction, Rect source, Rect rect1, Rect rect2) {
    final boolean rect1InSrcBeam = beamsOverlap(direction, source, rect1);
    final boolean rect2InSrcBeam = beamsOverlap(direction, source, rect2);

    // rect1 不是独占 beam → 不赢
    if (rect2InSrcBeam || !rect1InSrcBeam) return false;

    // rect1 在 beam 里，rect2 不在
    // 如果 rect1 在目标方向而 rect2 不在 → rect1 赢
    if (!isToDirectionOf(direction, source, rect2)) return true;

    // 水平方向：独占 beam 永远赢
    if (direction == SEARCH_FOCUS_LEFT || direction == SEARCH_FOCUS_RIGHT) return true;

    // 垂直方向：beam 只能赢到一定程度
    return majorAxisDistance(direction, source, rect1)
            < majorAxisDistanceToFarEdge(direction, source, rect2);
}

// ===== beamsOverlap =====
private boolean beamsOverlap(int direction, Rect rect1, Rect rect2) {
    switch (direction) {
        case SEARCH_FOCUS_LEFT:
        case SEARCH_FOCUS_RIGHT:
            return (rect2.bottom >= rect1.top) && (rect2.top < rect1.bottom);
        case SEARCH_FOCUS_UP:
        case SEARCH_FOCUS_DOWN:
            return (rect2.right >= rect1.left) && (rect2.left < rect1.right);
    }
    throw new IllegalArgumentException("direction must be a SearchDirection");
}

// ===== getWeightedDistanceFor（13 倍主轴权重）=====
private int getWeightedDistanceFor(int majorAxisDistance, int minorAxisDistance) {
    if (majorAxisDistance > 10000 || minorAxisDistance > 10000) {
        return Integer.MAX_VALUE;
    } else {
        // 不会溢出；最大值 1400000000 < Integer.MAX_VALUE
        return 13 * majorAxisDistance * majorAxisDistance
                + minorAxisDistance * minorAxisDistance;
    }
}
```

### 三处差异的影响

| 差异 | 影响 |
|---|---|
| `isToDirectionOf` 太宽松 | **部分重叠的节点被误判为候选** |
| 缺 `beamBeats` | **斜向节点可能被选中，正前方反而选不中** |
| 缺 `getWeightedDistanceFor` | **距离权重不对**（TalkBack 主轴权重 13 倍） |

### 建议改法（完整替换）

```kotlin
/**
 * 比较候选 —— 1:1 抄 TalkBack DirectionalTraversalStrategy:343-427
 */
private fun isBetterCandidate(
    direction: Int, source: Rect, rect1: Rect, rect2: Rect
): Boolean {
    // ① 候选资格
    if (!isCandidate(source, rect1, direction)) return false
    // ② rect2 不是候选 → rect1 胜
    if (!isCandidate(source, rect2, direction)) return true
    // ③ beam 判定
    if (beamBeats(direction, source, rect1, rect2)) return true
    // ④ 反向 beam
    if (beamBeats(direction, source, rect2, rect1)) return false
    // ⑤ 加权距离
    return weightedDistance(direction, source, rect1) <
           weightedDistance(direction, source, rect2)
}

/**
 * 候选资格 —— 1:1 抄 TalkBack isCandidate
 */
private fun isCandidate(src: Rect, dest: Rect, direction: Int): Boolean =
    when (direction) {
        TraversalDirection.LEFT ->
            (src.right > dest.right || src.left >= dest.right) && src.left > dest.left
        TraversalDirection.RIGHT ->
            (src.left < dest.left || src.right <= dest.left) && src.right < dest.right
        TraversalDirection.UP ->
            (src.bottom > dest.bottom || src.top >= dest.bottom) && src.top > dest.top
        TraversalDirection.DOWN ->
            (src.top < dest.top || src.bottom <= dest.top) && src.bottom < dest.bottom
        else -> false
    }

/**
 * beam 判定 —— 1:1 抄 TalkBack beamBeats
 */
private fun beamBeats(direction: Int, source: Rect, rect1: Rect, rect2: Rect): Boolean {
    val r1InBeam = beamsOverlap(direction, source, rect1)
    val r2InBeam = beamsOverlap(direction, source, rect2)
    if (r2InBeam || !r1InBeam) return false
    if (!isToDirectionOf(direction, source, rect2)) return true
    if (direction == TraversalDirection.LEFT ||
        direction == TraversalDirection.RIGHT) return true
    return majorAxisDistance(direction, source, rect1) <
           majorAxisDistanceToFarEdge(direction, source, rect2)
}

/**
 * beam 重叠 —— 1:1 抄 TalkBack beamsOverlap
 */
private fun beamsOverlap(direction: Int, rect1: Rect, rect2: Rect): Boolean =
    when (direction) {
        TraversalDirection.LEFT, TraversalDirection.RIGHT ->
            rect2.bottom >= rect1.top && rect2.top < rect1.bottom
        TraversalDirection.UP, TraversalDirection.DOWN ->
            rect2.right >= rect1.left && rect2.left < rect1.right
        else -> false
    }

/**
 * 加权距离 —— 1:1 抄 TalkBack getWeightedDistanceFor
 *
 * 主轴权重 13 倍，这是「优先选正前方」的量化表达。
 */
private fun weightedDistance(direction: Int, source: Rect, dest: Rect): Int {
    val major = majorAxisDistance(direction, source, dest)
    val minor = minorAxisDistance(direction, source, dest)
    if (major > 10000 || minor > 10000) return Int.MAX_VALUE
    return 13 * major * major + minor * minor
}

/**
 * 主轴到远边距离 —— 1:1 抄 TalkBack majorAxisDistanceToFarEdge
 */
private fun majorAxisDistanceToFarEdge(direction: Int, source: Rect, dest: Rect): Int =
    when (direction) {
        TraversalDirection.LEFT -> (source.left - dest.right).coerceAtLeast(1)
        TraversalDirection.RIGHT -> (dest.left - source.right).coerceAtLeast(1)
        TraversalDirection.UP -> (source.top - dest.bottom).coerceAtLeast(1)
        TraversalDirection.DOWN -> (dest.top - source.bottom).coerceAtLeast(1)
        else -> 0
    }
```

### 🔴 A1：`NodeFilter.CachedFilter` 缓存污染（定时炸弹）

### 🟠 A2：`FocusSearch.findFirstFocus(BACKWARD)` 永远返回 null

## 十一、总结

**框架整体抄得不错，但有个结构性缺口：**

```
① 遍历层（在树里走）      ← 我们有了 ✅
② 窗口层（在窗口间走）    ← 我们完全没有 ❌ P0
③ 恢复层（焦点丢了找回来）← 我们只有简化版 ⚠️ P0
```

**我们只做了 ①。**

**这解释了为什么「焦点会丢失、找不到焦点」** —— 一旦焦点离开当前窗口（弹窗、输入法、悬浮窗），或者滚动后节点被回收，**没有任何机制把它找回来**。

**建议顺序：**
1. **先补 P0-1 跨窗口导航** —— 这是「焦点丢失」最直接的根因
2. **再补 P0-2 滚动恢复** —— 解决滚动场景的焦点丢失
3. **然后 P1-1 SpatialTraversal** —— 空间导航准确性
4. 其余按需
